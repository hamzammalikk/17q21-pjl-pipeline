# 17q21 asthma locus in 1000 Genomes PJL: a laptop-scale variant analysis pipeline

A complete, command-line workflow from public sequencing reads to annotated candidate variants, applied to the 17q12-q21 asthma locus (*ZPBP2*, *GSDMB*, *ORMDL3*, *GSDMA*, *IKZF3*) in 96 unrelated Punjabi individuals from Lahore (PJL) from the 1000 Genomes Project 30x high-coverage data (GRCh38, window `chr17:39,700,000-40,000,000`).

## What the pipeline does

| Step | What happens | Main tools |
|---|---|---|
| 1. Data | Select 96 unrelated PJL samples and extract the 300 kb window from the phased 1000 Genomes VCF | bcftools |
| 2. Re-alignment (5 individuals) | Extract window reads from public CRAM files, clean them, align to chr17 | samtools, fastp, bwa-mem2 |
| 3. Variant calling | Call, normalise and filter variants; benchmark SNPs against the published 1000 Genomes genotypes | bcftools |
| 4. Population genetics (96 individuals) | Convert to PLINK, QC, LD with the lead SNP rs7216389, haplotype blocks, LD heatmap | PLINK 1.9 / 2, Python |
| 5. Annotation and eQTL | Predicted variant effects (Ensembl VEP REST) and GTEx v8 eQTL matching; final merged table | Python |

## Requirements

- Linux, or Windows with WSL2 (Ubuntu). macOS may work but was not tested (bwa-mem2 is easiest on Linux).
- [Miniforge](https://github.com/conda-forge/miniforge) (conda/mamba)
- About 2 GB of free disk space and an internet connection (data are streamed from public servers)

## Installation

```bash
mamba env create -f environment.yml
# or, without the file:
mamba create -n pjl17q21 -c conda-forge -c bioconda \
  samtools bcftools htslib bwa-mem2 fastp plink plink2 python pandas numpy matplotlib
```

Versions used: samtools 1.24, bcftools 1.24, bwa-mem2 2.2.1, fastp 1.3.7, PLINK 1.9.0-b.8, PLINK 2.0.0-a.6.9LM.

## Running

`run_pipeline.sh` assumes the project lives in `~/pjl_17q21`, so clone the repository there:

```bash
 git clone https://github.com/hamzammalikk/17q21-pjl-pipeline ~/pjl_17q21
cd ~/pjl_17q21
conda activate pjl17q21
bash run_pipeline.sh
```

The script skips downloads and heavy steps whose outputs already exist. It prints sanity-check numbers at each stage (expected values are listed below).

## Repository contents

```
run_pipeline.sh          all steps in order
environment.yml          conda environment
scripts/
  ld_heatmap.py          LD heatmap from the PLINK r2 matrix
  vep_rest.py            variant annotation through the Ensembl VEP REST service
  eqtl_lookup.py         GTEx v8 significant eQTLs for the candidates (GTEx Portal API)
  merge_final.py         merges LD, VEP, allele frequency and eQTL into one table
results_small/           small result files from our run (no raw or large data)
  final_table.tsv        the 108 candidate SNPs with r2 >= 0.6 with the lead SNP
  ld_lead.ld             LD (r2) of every SNP within 500 kb with rs7216389
  blocks.blocks.det      PLINK haplotype blocks
  vep.tsv, eqtl_hits.tsv annotation and eQTL results
  pjl17.qc.afreq         ALT allele frequencies in the 96 PJL individuals
  Supplementary_Table_S1.csv   compact version of the final table
  ld_heatmap.png         LD heatmap
```

Raw data, references, BAM/FASTQ files and the regional VCF are **not** stored here. They are regenerated by the pipeline from public sources.

## Notes and limitations

- The analysis is descriptive. It does not test association with asthma, and it cannot identify the causal variant among variants in strong LD.
- Alignment uses a chromosome 17-only reference, so reads from paralogous sequence elsewhere in the genome could align there with inflated confidence.
- The variant-calling benchmark uses five individuals and biallelic SNPs, and the published genotypes come from the same reads, so the benchmark is not independent of the data.
- GTEx donors are mostly of European ancestry.
- The lead SNP (rs7216389) and the r2 >= 0.6 threshold were chosen in advance from the literature and are conventions.
